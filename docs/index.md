**BdPy** (BrainDecoderToolbox for Python) is a Python package for brain decoding analysis, developed by [Kamitani Lab](https://github.com/KamitaniLab) at Kyoto University and ATR.

## Features

- **BData format** — a structured container for fMRI data, stimuli, and experimental metadata
- **Machine learning utilities** — wrappers and helpers for brain decoding workflows
- **MRI preprocessing** — tools for working with neuroimaging data (NIfTI, SPM)
- **Deep learning integration** — feature extraction via Caffe and PyTorch
- **Reconstruction** — image reconstruction methods from brain activity
- **Pipeline support** — configuration-driven experiment pipelines
